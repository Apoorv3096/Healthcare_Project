🏥 Healthcare Analytics Dashboard | Power BI
📌 Project Overview

This project presents an end-to-end Healthcare Analytics solution developed in Power BI to analyze hospital billing performance and patient appointment management. The dashboard helps healthcare administrators track revenue, payment collection efficiency, appointment trends, patient visit patterns, and operational performance across multiple healthcare facilities.

🎯 Business Problem

Healthcare organizations often struggle with:

Tracking payment collection performance
Monitoring failed and pending payments
Understanding appointment completion and cancellation rates
Identifying high-performing hospitals and departments
Analyzing patient visit trends for resource planning

This dashboard provides actionable insights to help healthcare stakeholders make data-driven decisions.
